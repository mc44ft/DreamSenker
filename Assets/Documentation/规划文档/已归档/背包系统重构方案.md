# 背包系统重构方案

## 计划说明

本次计划把手写的背包思路整理成可执行方案。目标不是做完整任务系统，也不是扩成复杂背包框架，而是先把背包自身做清楚：物品配置、存档数量、使用效果、格子展示、标签页切换各自归位。

执行后，背包会从“UI 直接读写字典和触发效果”调整为“`InventoryManager` 统一管理背包数据，`PropEffectResolver` 统一执行道具效果，`PackagePanel` 只负责展示和点击”。同类物品只显示一个格子，并通过数量文本展示数量。

## 结论

本次做：

- 物品类型配置继续使用 `PackageItemInfo`。
- 背包存档继续使用 `PackageData.PackageDict`。
- 新增物品分类 `EPackageItemCategory`，区分道具和任务物品。
- 新增 `InventoryItemStack`，作为单个格子的展示数据。
- 新增 `PropEffectResolver`，集中处理道具使用效果。
- `InventoryManager` 收口背包增删查用。
- `PackagePanel` 按标签页刷新格子。
- `PackagePanelSlot` 作为格子 UI 实例，负责图标、数量、选中态。

本次不做：

- 不做任务系统重构。
- 不改 `TaskPanel` 的任务发布和交付流程。
- 不做拖拽换位。
- 不做装备、随机词条、独立物品实例。
- 不引入 UI Toolkit。
- 不把背包拆成多份存档字典。

保持不变：

- `EPackageItemType` 继续作为当前物品类型标识。
- `PackageData` 继续只保存每种物品的数量。
- 背包打开流程仍由输入事件进入 UI 面板。
- `PackagePanelSlot` 仍使用 `Toggle` / `ToggleGroup` 做单选。

## 最终结构

```text
PackageItemInfo
  -> EPackageItemType
  -> EPackageItemCategory
  -> Icon
  -> Description
  -> EBonusEffectType
  -> BonusAmount
  -> MaxStack

PackageData
  -> Dictionary<EPackageItemType, int>

InventoryManager
  -> SetupData()
  -> ResetData()
  -> TryAddItem()
  -> TryRemoveItem()
  -> TryUseItem()
  -> CanUseItem()
  -> HasItem()
  -> GetItemStacks(category)
  -> PropEffectResolver

PropEffectResolver
  -> TryApply(PackageItemInfo)

PackagePanel
  -> SwitchCategory()
  -> Refresh()
  -> SelectSlot()
  -> UseSelectedSlot()

PackagePanelSlot
  -> Initialize(InventoryItemStack)
  -> SetIcon()
  -> SetCount()
  -> SetSelected()
```

主要调用链：

```text
玩家打开背包
  -> InputManager
  -> GameplayUiInputHandler
  -> UIManager.ShowPanel<PackagePanel>()
  -> PackagePanel.Refresh()
  -> InventoryManager.GetItemStacks(EPackageItemCategory.Usable)
```

```text
玩家点击格子
  -> PackagePanelSlot.Toggle
  -> PackagePanel.SelectSlot()
  -> 显示 PackageItemInfo.Description
```

```text
玩家点击使用
  -> PackagePanel.UseSelectedSlot()
  -> InventoryManager.TryUseItem()
  -> PropEffectResolver.TryApply(PackageItemInfo)
  -> 成功后扣除数量
  -> PackagePanel.Refresh()
```

标识符说明：

- `EPackageItemType`：已有物品类型枚举。
- `EPackageItemCategory`：新增物品分类枚举，建议包含 `Unknown`、`Usable`、`Quest`。
- `EBonusEffectType`：已有道具效果类型枚举。
- `InventoryItemStack`：新增展示数据，不是 UI 实例。
- `PackagePanelSlot`：背包格子的 UI 实例。

## 改动清单

### 新增

- `Assets/Scripts/Inventory/InventoryItemStack.cs`
  - 定义单个格子的展示数据。
  - 字段包含物品类型、数量、物品配置。

- `Assets/Scripts/Inventory/PropEffectResolver.cs`
  - 普通 C# 类，不做单例。
  - 由 `InventoryManager` 持有并创建。
  - 提供 `TryApply(PackageItemInfo itemInfo)`。
  - 根据 `PackageItemInfo.BonusEffectType` 和 `BonusAmount` 执行效果。

### 修改

- `Assets/Scripts/Shared/Enums.cs`
  - 新增 `EPackageItemCategory`。
  - 默认值使用 `Unknown = 0`，避免未配置物品被误认为普通道具。

- `Assets/Scripts/Data/Configs/PackageItemConfigSO.cs`
  - `PackageItemInfo` 增加 `EPackageItemCategory Category`。
  - `PackageItemInfo` 增加 `int MaxStack`。
  - 保留现有物品类型、图标、描述、效果类型、效果数值。

- `Assets/Scripts/Inventory/InventoryManager.cs`
  - 持有 `PackageData` 和 `PackageItemConfigSO`。
  - 内部创建并持有 `PropEffectResolver`。
  - 增加 `ResetData()`，用于退出游戏或回主菜单时恢复未初始化状态。
  - 增加 `TryAddItem()`、`TryRemoveItem()`、`TryUseItem()`、`CanUseItem()`、`HasItem()`。
  - 增加 `GetItemStacks(EPackageItemCategory category)`，为背包面板提供当前标签页格子数据。

- `Assets/Scripts/UI/Panels/Inventory/PackagePanel.cs`
  - 默认打开道具页。
  - 根据当前 `EPackageItemCategory` 调用 `InventoryManager.GetItemStacks()`。
  - 使用 `InventoryItemStack` 初始化格子。
  - 选中格子后显示描述。
  - 使用物品时只调用 `InventoryManager.TryUseItem()`。
  - 不再直接遍历 `PackageData.PackageDict`。
  - 不再直接触发道具效果事件。

- `Assets/Scripts/UI/Panels/Inventory/PackagePanelSlot.cs`
  - 作为格子 UI 实例保留。
  - 初始化时接收 `InventoryItemStack`。
  - 显示图标和数量。
  - 通过 `ToggleGroup` 维持单选。
  - 对象池回收时清理选中状态、回调、缩放和数量显示。

- `Assets/Scripts/Inventory/ItemPickUp.cs`
  - 拾取后调用 `InventoryManager.TryAddItem()`。
  - 只负责世界物品拾取，不处理背包 UI。

### 不修改

- `Assets/Scripts/Data/Runtime/PackageData.cs`
  - 继续只存 `Dictionary<EPackageItemType, int>`。

- `Assets/Scripts/UI/Panels/TaskPanel.cs`
  - 本次不处理任务系统。

- `Assets/Scripts/Managers/GamePlayUiController.cs`
  - 本次不改名，不拆分。

- `Assets/Documentation/思路整理/背包系统思路整理.md`
  - 保持原文件不动。

## 执行顺序

1. 新增 `EPackageItemCategory`，补齐物品分类枚举。
2. 修改 `PackageItemInfo`，加入分类和堆叠数量字段。
3. 新增 `InventoryItemStack`，定义 UI 展示数据。
4. 新增 `PropEffectResolver`，集中执行道具效果。
5. 扩展 `InventoryManager`，完成数据注入、重置、增删查用。
6. 修改 `PackagePanelSlot`，支持 `InventoryItemStack`、数量显示和对象池清理。
7. 修改 `PackagePanel`，按标签页刷新格子并通过 `InventoryManager` 使用物品。
8. 修改 `ItemPickUp`，将拾取入口切到 `TryAddItem()`。
9. 扫描旧调用，确认 UI 不再直接读写 `PackageData.PackageDict`。

## 验证

引用检查：

```bash
rg -n "PackageData\\.PackageDict|AddItemToPackage|RemoveItemFromPackage|TryAddItem|TryRemoveItem|TryUseItem|GetItemStacks|InventoryItemStack|PropEffectResolver|EPackageItemCategory" Assets/Scripts
```

Diff 检查：

```bash
git diff --check
```

Unity Console 检查：

- 检查 Console 中是否存在 Error / Exception。

运行验证：

- 打开背包时默认显示道具页。
- 同类物品只生成一个格子。
- 多个同类物品在格子上显示数量。
- 点击格子后只选中一个格子，并显示对应物品描述。
- 使用可用道具后执行效果，数量减少。
- 数量减到 0 时，该格子从当前标签页消失。
- 切换到任务物品页时，只显示 `Category = Quest` 的物品。
- 任务物品不走本次使用逻辑。
- 拾取世界物品后，背包数量增加。

人工配置确认：

- 每个 `PackageItemInfo` 都配置了 `Category`。
- 每个 `PackageItemInfo` 都配置了合理的 `MaxStack`。
- 背包格子 Prefab 中数量文本、Toggle、图标引用由用户在 Inspector 中绑定。
