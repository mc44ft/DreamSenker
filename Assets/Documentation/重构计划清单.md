# DreamSenker 重构计划清单

**制定日期**: 2026-03-29
**项目定位**: 个人作品集 · AI 辅助编码展示 · 游戏设计能力展示

---

## 一、项目愿景

以**空洞骑士**为核心参照，打造一款 **2D 探索向动作游戏**：

- **核心体验**：探索感 > 战斗深度，关卡设计 + 叙事驱动
- **展示能力**：AI 辅助编码、项目管控、游戏设计思路
- **目标受众**：面试/作品集展示，面向游戏开发岗位

## 三、重构/新建内容

### 3.1 代码架构

- [ ] **统一状态机** — 所有角色（玩家 + 敌人 + Boss）迁移到 PlayArk.StateMachine
- [ ] **重构 MapSystem** — 完善关卡图编辑器，支持更复杂的联通逻辑
- [ ] **扩展 DialogueSystem** — 添加条件判断、变量系统、任务节点
- [ ] **新建 TaskSystem** — 完整的任务系统（接取/追踪/完成/奖励）
- [ ] **新建 EventSystem** — 事件驱动系统，支持全局事件注册
- [ ] **重构 UI 架构** — 面板生命周期管理，适配新的事件系统

### 3.2 游戏内容

- [ ] **关卡设计** — 重新规划地图联通，构建探索路径
- [ ] **敌人重做** — 迁移到可视化状态机，重新设计行为
- [ ] **Boss 战** — 重新设计 3 个 Boss（蜘蛛、狐狸 x2）
- [ ] **美术资源** — 整体重新制作（角色、场景、UI）
- [ ] **叙事内容** — 设计碎片化叙事，对话内容填充

### 3.3 工具链

- [ ] **编辑器工具完善** — 状态机、对话、任务、地图编辑器
- [ ] **调试工具** — 可视化状态查看、变量监视
- [ ] **数据配置化** — 将更多硬编码逻辑迁移到 ScriptableObject

## 四、优先级排序

### Phase 1 · 架构奠基（当前状态 → 可运行原型）
> 目标：建立可验证的开发框架

1. 统一状态机（所有角色迁移到 PlayArk.StateMachine）
2. 完善 MapSystem（关卡图编辑器 + 联通逻辑）
3. 扩展 DialogueSystem（条件/变量/任务节点）
4. 新建 TaskSystem（基础框架）
5. 重构 Framework 基础设施（单例、事件、对象池）

### Phase 2 · 内容填充
> 目标：完成第一个可玩的关卡原型

1. 关卡设计（CampMap 重做，联通路径）
2. 玩家移动 + 战斗手感打磨
3. 第一个普通敌人完成
4. 第一个 Boss 完成
5. 基础对话 + 简单任务

### Phase 3 · 系统完善
> 目标：完整的探索体验

1. 任务系统完整功能
2. 存档系统完善
3. UI 面板体系完善
4. 音效/震动/反馈打磨

### Phase 4 · 美术 & 打磨
> 目标：达到作品集展示质量

1. 整体美术重制
2. 场景氛围搭建
3. Boss 战完整设计
4. 叙事内容填充
5. 性能优化
