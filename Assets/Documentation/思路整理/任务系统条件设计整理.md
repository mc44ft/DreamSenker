# 任务系统条件设计整理

## 目标

替换 `EGameCondition`。

不要再把所有游戏状态塞进一个枚举里。对话配置改为挂一组 `DialogueConditionSO`，每个条件自己判断是否满足。

```text
DialogueNpcTriggerInfo
-> Conditions[]
-> condition.IsMet()
-> 全部满足后播放 DialogueGraph
```

## 基本流程

接取任务：

```text
NPC 对话
-> 条件判断通过
-> 播放发布任务对话
-> DialogueNodeTaskPublish 打开任务面板
-> 玩家点击接取
-> QuestManager.StartQuest(questId)
```

交付任务：

```text
NPC 对话
-> 条件判断通过
-> 播放交付任务对话
-> 打开交付面板
-> 玩家点击交付
-> QuestManager.CompleteQuest(questId)
```

## 新增枚举

### EQuestState

只记录任务长期状态。

```csharp
public enum EQuestState
{
    // 任务未接取
    NotStarted,
    // 任务已接取，进行中
    Active,
    // 任务已完成
    Completed
}
```

不加 `ReadyToDeliver`。  
是否可交付由 `QuestManager.CanCompleteQuest(questId)` 动态判断。

## 新增 QuestManager

任务系统入口。

```csharp
public class QuestManager : BaseManager<QuestManager>
{
    // 接取任务
    public void StartQuest(string questId);

    // 判断任务当前是否满足交付条件
    public bool CanCompleteQuest(string questId);

    // 交付任务
    public bool CompleteQuest(string questId);

    // 获取任务当前状态
    public EQuestState GetQuestState(string questId);
}
```

职责：

- `StartQuest`：接取任务。
- `CanCompleteQuest`：判断任务当前是否可交付。
- `CompleteQuest`：交付任务，扣物品，改状态。
- `GetQuestState`：查询任务状态。

## 新增对话条件

### DialogueConditionSO

对话条件基类。

```csharp
public abstract class DialogueConditionSO : ScriptableObject
{
    // 判断当前条件是否满足
    public abstract bool IsMet();
}
```

### QuestStateDialogueConditionSO

判断任务状态。

```csharp
[CreateAssetMenu(menuName = "DreamSenker/Dialogue Conditions/Quest State")]
public class QuestStateDialogueConditionSO : DialogueConditionSO
{
    // 要判断的任务配置
    [SerializeField] private QuestDefinitionSO _questDefinition;
    // 需要满足的任务状态
    [SerializeField] private EQuestState _requiredState;

    // 判断任务当前状态是否等于配置状态
    public override bool IsMet()
    {
        return QuestManager.Instance.GetQuestState(_questDefinition.QuestId) == _requiredState;
    }
}
```

### QuestCompletableDialogueConditionSO

判断任务当前是否可交付。

```csharp
[CreateAssetMenu(menuName = "DreamSenker/Dialogue Conditions/Quest Completable")]
public class QuestCompletableDialogueConditionSO : DialogueConditionSO
{
    // 要判断的任务配置
    [SerializeField] private QuestDefinitionSO _questDefinition;
    // 期望的可交付结果
    [SerializeField] private bool _expectedValue;

    // 判断任务当前可交付结果是否等于期望值
    public override bool IsMet()
    {
        return QuestManager.Instance.CanCompleteQuest(_questDefinition.QuestId) == _expectedValue;
    }
}
```

## 修改触发器判断

### DialogueNpcTrigger / DialogueOneTrigger

新增统一判断函数。

```csharp
private bool CheckConditions(DialogueConditionSO[] conditions)
{
    // 没有配置条件时默认通过
    if (conditions == null || conditions.Length == 0)
        return true;

    foreach (var condition in conditions)
    {
        // 空条件跳过，避免单个配置缺失阻断整条对话
        if (condition == null)
            continue;

        // 任意条件不满足，则当前对话配置不可用
        if (!condition.IsMet())
            return false;
    }

    // 所有条件满足，当前对话配置可用
    return true;
}
```

原来的：

```csharp
GameManager.Instance.CheckGameCondition(info.eGameCondition)
```

替换为：

```csharp
CheckConditions(info.Conditions)
```

```text
RequiredState = NotStarted
```

```text
QuestStateDialogueConditionSO

```

```text
QuestStateDialogueConditionSO
```
