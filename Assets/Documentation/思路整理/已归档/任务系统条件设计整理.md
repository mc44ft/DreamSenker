# 任务系统条件设计整理

## 目标

在已有 `DialogueConditionSO` 条件系统上，补充任务系统需要的任务状态条件和任务交付条件。

## 基本流程

接取任务：

```text
NPC 对话
-> 条件判断通过
-> 播放发布任务对话
-> DialogueNodeTaskPublish 打开任务面板
-> 玩家点击接取
-> QuestManager.StartQuest(questId)
```

交付任务：

```text
NPC 对话
-> 条件判断通过
-> 播放交付任务对话
-> 打开交付面板
-> 玩家点击交付
-> QuestManager.CompleteQuest(questId)
```

## 新增枚举

### EQuestState

只记录任务长期状态。

```csharp
public enum EQuestState
{
    // 任务未接取
    NotStarted,
    // 任务已接取，进行中
    Active,
    // 任务已完成
    Completed
}
```

不加 `ReadyToDeliver`。  
是否可交付由 `QuestManager.CanCompleteQuest(questId)` 动态判断。

## 新增任务数据结构

### QuestDefinitionSO

任务配置。

```csharp
[CreateAssetMenu(menuName = "DreamSenker/Quest/Quest Definition")]
public class QuestDefinitionSO : ScriptableObject
{
    // 任务唯一 ID，用于存档和运行时查询
    [SerializeField] private string _questId;
    // 任务标题，用于任务面板显示
    [SerializeField] private string _title;
    // 任务描述，用于任务面板显示
    [SerializeField] private string _description;
    // 任务目标文本，用于任务追踪 UI
    [SerializeField] private string _objectiveText;
    // 完成任务需要的物品列表
    [SerializeField] private QuestItemRequirement[] _requiredItems;

    // 获取任务唯一 ID
    public string QuestId => _questId;
    // 获取任务标题
    public string Title => _title;
    // 获取任务描述
    public string Description => _description;
    // 获取任务目标文本
    public string ObjectiveText => _objectiveText;
    // 获取任务需求物品
    public IReadOnlyList<QuestItemRequirement> RequiredItems => _requiredItems;
}
```

## 新增 QuestManager

任务系统入口。

```csharp
public class QuestManager : BaseManager<QuestManager>
{
    // 接取任务
    public void StartQuest(string questId);

    // 判断任务当前是否满足交付条件
    public bool CanCompleteQuest(string questId);

    // 交付任务
    public bool CompleteQuest(string questId);

    // 获取任务当前状态
    public EQuestState GetQuestState(string questId);
}
```

职责：

- `StartQuest`：接取任务。
- `CanCompleteQuest`：判断任务当前是否可交付。
- `CompleteQuest`：交付任务，扣物品，改状态。
- `GetQuestState`：查询任务状态。

## 新增任务对话条件

### QuestStateDialogueConditionSO

判断任务状态。

```csharp
[CreateAssetMenu(menuName = "DreamSenker/Dialogue Conditions/Quest State")]
public class QuestStateDialogueConditionSO : DialogueConditionSO
{
    // 要判断的任务配置
    [SerializeField] private QuestDefinitionSO _questDefinition;
    // 需要满足的任务状态
    [SerializeField] private EQuestState _requiredState;

    // 判断任务当前状态是否等于配置状态
    public override bool IsMet()
    {
        return QuestManager.Instance.GetQuestState(_questDefinition.QuestId) == _requiredState;
    }
}
```

### QuestCompletableDialogueConditionSO

判断任务当前是否可交付。

```csharp
[CreateAssetMenu(menuName = "DreamSenker/Dialogue Conditions/Quest Completable")]
public class QuestCompletableDialogueConditionSO : DialogueConditionSO
{
    // 要判断的任务配置
    [SerializeField] private QuestDefinitionSO _questDefinition;
    // 期望的可交付结果
    [SerializeField] private bool _expectedValue;

    // 判断任务当前可交付结果是否等于期望值
    public override bool IsMet()
    {
        return QuestManager.Instance.CanCompleteQuest(_questDefinition.QuestId) == _expectedValue;
    }
}
```

## 对话配置示例

### 未接取，发布任务

```text
QuestStateDialogueConditionSO
Quest = 寻找晨露梦核
RequiredState = NotStarted
```

### 已接取，不可交付

```text
QuestStateDialogueConditionSO
Quest = 寻找晨露梦核
RequiredState = Active

QuestCompletableDialogueConditionSO
Quest = 寻找晨露梦核
ExpectedValue = false
```

### 已接取，可交付

```text
QuestStateDialogueConditionSO
Quest = 寻找晨露梦核
RequiredState = Active

QuestCompletableDialogueConditionSO
Quest = 寻找晨露梦核
ExpectedValue = true
```

### 已完成

```text
QuestStateDialogueConditionSO
Quest = 寻找晨露梦核
RequiredState = Completed
```
