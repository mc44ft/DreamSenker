##对话系统方向
要改变DialogueNodeExternalUI转交外部控制权 打开外部面板 外部面板执行结束后继续对话图的功能
当前的EventCenter方案调用链路不太清晰，决定新增一个DialogueExternalUIRunner来协调对话系统和UI

DialogueExternalUIRunner（新增）
由 DialogueManager 持有
结构如下：
public class DialogueExternalUIRunner
{
public void OpenTaskPanel(
QuestDefinitionSO questDefinition,
TaskPanel.E_PanelMode mode,
Action<int> onFinished)
{
UIManager.Instance.ShowPanel<TaskPanel>(E_UILayer.Top, panel =>
{
panel.Initialize(questDefinition, mode, resultIndex =>
{
UIManager.Instance.HidePanel<TaskPanel>();
onFinished?.Invoke(resultIndex);//这个onFinished执行的就是DialogueNodeBase节点完成的方法OnFinished()
});
});
}
}

DialogueNodeExternalUI
这是一个抽象类节点，该类节点可以将自身的控制权暂时转交给外部，可用于在对话途中打开面板（接取任务、交付任务、获取奖励等）
resultIndex目前只记录了但是没有用到，可以直接删掉，后面再重新考虑这个设计
其子类可以通过以下链路打开对应面板
-> DialogueExternalUIRunner.OpenTaskPanel(panelType, payload（直接传入QuestDefinitionSO即可，目前只考虑任务面板）, onFinished)
-> Runner 打开具体 UI
-> UI 完成后回调 Runner
-> Runner 调用 onFinished()

节点不直接管 EventCenter，面板也不直接通知 DialogueNodeExternalUI。

##任务系统方向
QuestDefinitionSO（新增）
是任务系统的配置文件
提供如下字段：
-> QuestId（guid QuestDefinitionSO 创建时，如果 _questId 为空，就生成一次 之后不再自动改 Inspector 只读显示）
-> 任务标题
-> 任务描述
-> 需要物品（QuestItemRequirement）
-> 目标描述 任务栏显示的文本（这个任务栏可以先不做，但字段保留在这里）

QuestItemRequirement（新增）
任务需求物品
提供如下字段：
    EPackageItemType ItemType 
    int Amount

QuestRuntimeData（新增）
玩家存储的数据，用来标明每个任务的完成状态
以列表形式存放在GameSaveData
-> QuestId
-> QuestState（枚举值）

EQuestState（新增）
结构如下
public enum EQuestState
{
NotStarted,--任务未接取
Active,--任务进行中
Completed,--任务完成
}

QuestManager ：BaseManager（新增）
所需配置数据由GameManager注入（任务配置资源文件List<QuestDefinitionSO>、GameSaveData.QuestRuntimeData）
GameSaveData.QuestRuntimeData是唯一数据源，由QuestManager负责读写
在 Player.Initialize 后与背包管理器一起初始化
任务管理器 
提供如下方法：
-> StartQuest(id) --接取任务的方法
    重复接取 & 找不到对应任务：返回false 打waraning 
-> CanCompleteQuest(id) --检测任务是否完成（可交付）的方法
-> CompleteQuest(id) -- 交付任务的方法（负责：扣除需求物品 改任务状态）
-> GetQuestState(id) --获取当前任务状态的方法

DialogueNodeTaskPublish
需要新增QuestDefinitionSO类型字段，只需要将对应的任务配置到对话任务发布节点上即可
该对话任务发布节点 不仅能知道任务ID，也能知道任务需要物品、任务描述等，方便直接传递给 任务发布面板

DialogueShowPanelEventArgs（删除，不需要通过事件中心来协调UI系统和对话系统了）

提供如下字段：

用于判断任务是否可交付的对话条件资源
提供如下字段：
    任务资源
    期望的可交付结果（bool值）

玩家接取任务流程：
玩家与发布任务的NPC对话->判断能否触发发布任务对话->能触发
对话到发布任务的对话节点->打开任务发布面板->玩家点击UI按钮接取任务->QuestManager调用StartQuest->继续后续对话流程
玩家交付任务流程:
玩家与交付任务的NPC对话->判断能否触发交付任务对话->能触发
->对话到交付任务的对话节点->打开交付面板->玩家点击交付->QuestManager调用CompleteQuest->继续后续对话流程
