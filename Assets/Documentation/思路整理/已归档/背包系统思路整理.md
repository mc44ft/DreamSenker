# 背包系统思路整理

## 背包数据层

### PackageItemInfo

用于定义不同物品类型的固有状态。这里是一个享元模式，就是说所有同类型的物品都共享这一份数据。

同一类型物品之间可以有不同的数据，但目前不需要区分。如果装备、道具有随机词条，可以进行区分。

这个类定义了如下字段：

- 物品类型：枚举项 `EPackageItemType`
- 物品图标：`Sprite`
- 物品描述：`string`
- 物品效果类型：枚举项 `EBonusEffectType`
- 物品效果强度数值：`int`，回血量、回蓝量等
- 物品标签：枚举项需要新增 `EPackageItemCategory`，道具 / 任务物品
- 该物品所能堆叠的最大数量：`int`

### PackageItemConfigSO

存一个 `PackageItemInfo` 数组。

### PackageData

作为游戏可存储数据类，只存一个字典，记录每种类型的物品有多少。

## 效果执行层

### PropEffectResolver

是背包使用道具时的效果解释器。

将道具效果的触发全部放到这个类中。

不作为单例模式，由 `InventoryManager` 持有并创建它。

提供一个 `TryApply` 方法，需要传入 `PackageItemInfo`。如果方法查询到对应道具的效果函数，就执行，否则无事发生，不扣除物品。

## 运行时管理层

### InventoryManager

是背包系统的大 Boss。

提供如下方法：

- 注入数据的方法：`GameManager` 在初始化玩家后，调用 `InventoryManager.Instance.SetupData(...)`
- 恢复初始化 / 重置自己的方法：在退出游戏、回到游戏主菜单时调用
- 尝试增加新物品的方法
- 尝试移除已有物品的方法
- 尝试使用物品的方法
- 判断能否使用物品的方法
- 查询背包中物品信息的方法：比如背包里有没有某种物品，物品数量多少，主要用来交付任务时查询是否满足交付任务的条件
- 按标签页查询要显示的格子数据的方法：传入 `EPackageItemCategory`，返回 `IReadOnlyList<InventoryItemStack>`

### InventoryItemStack

是单个格子的展示数据，不是 UI 格子实例。

提供如下字段：

- 物品类型：`EPackageItemType`
- 物品数量：`int`，用于物品格子右下角显示数量
- 物品信息：`PackageItemInfo`，用于背包底部信息栏显示物品描述

## UI 展示层

### PackagePanel

背包面板类。

提供如下方法：

- 根据传入的物品标签，切换不同的背包标签页
- 刷新背包面板
- 选中某个格子的方法：可以在里面给对应格子加高亮显示
- 使用已经选中格子上的物品的方法：调用 `InventoryManager` 来使用

### PackagePanelSlot

这是背包格子的视图实例，用对象池来进行优化。

提供如下方法：

- 设置图标
- 设置当前格子数量
- 设置当前选中状态

## 调用思路整理

```text
玩家按下按键
  -> InputManager 响应
  -> 交给 GameplayUiInputHandler 触发打开背包面板
  -> 按照数据刷新背包面板，默认显示道具页
```

```text
玩家点击对应物品
  -> 对应的 PackagePanelSlot 处理选中
  -> 调用 PackagePanel 中选中格子的方法
  -> 显示物品信息
```

```text
玩家选中物品后点击使用
  -> 调用 PackagePanel 中使用已选中格子的方法
  -> 使用物品，同时格子上的数量减少 1 个
  -> 刷新面板
```

```text
ItemPickUp 挂载在物品实体上，非背包内
  -> 玩家靠近可以通过按键拾取物品
  -> 玩家拾取物品后，调用 InventoryManager 增加对应物品的数量
```
