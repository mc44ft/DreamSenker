# 背包系统说明文档

## 1. 系统概述

背包系统（Package System）是 DreamSenker 的道具拾取与使用系统，负责：

- 场景中道具的拾取交互
- 背包数据的增删查
- 暂停式背包 UI 面板的展示与操作
- 物品使用后的加成效果触发
- 背包数据的存档与读档

**当前规模**：3 种物品（红果、蓝果、晨露梦核），2 种加成效果（回血、回蓝）。

```
│                   逻辑层                         │
│  InventoryManager (单例)                         │
│  ├─ 持有 PackageData 引用                        │
│  ├─ 持有 PackageItemConfigSO 引用                │
│  └─ AddItem / RemoveItem / GetItemInfo           │
├─────────────────────────────────────────────────┤
│                   交互层                         │
│  ItemPickUp (场景 MonoBehaviour)                 │
│  └─ 碰撞检测 + 按键拾取 → AddItemToPackage       │
├─────────────────────────────────────────────────┤
│                   UI 层                          │
│  PackagePanel (面板)                             │
│  └─ PackagePanelItemIcon (格子, 对象池复用)       │
├─────────────────────────────────────────────────┤

│  RunningDataManager (单例)                       │
│  └─ JsonUtility 序列化 PlayerSaveData            │
└─────────────────────────────────────────────────┘
```

**依赖关系**：

```
GameManager
  ├─ 持有 PackageItemConfigSO 配置引用
  ├─ 持有 PlayerController → PlayerSaveData → PackageData
  └─ 初始化时调用 InventoryManager.SetupData()

InventoryManager (单例)
  ├─ PackageData → 指向 PlayerSaveData.PackageData（同一引用）
  └─ PackageItemConfigSO → 物品配置表

ItemPickUp (场景物体)
  └─ 拾取 → InventoryManager.AddItemToPackage()

GamePlayUiController
  └─ 监听 InputUI_PackagePanel → 显示/隐藏 PackagePanel

PackagePanel
  ├─ 显示时遍历 PackageData.PackageDict 生成格子
  ├─ 使用物品 → InventoryManager.RemoveItemFromPackage()
  └─ 触发 Game_BonusEffect 事件

TaskPanel
  └─ 任务交付 → InventoryManager.RemoveItemFromPackage(Chen)
```

## 4. 数据流

```
拾取流程：
  ItemPickUp.OnTriggerEnter2D → 显示提示
  → InputManager.PickupButtonDown
  → InventoryManager.AddItemToPackage(itemID)
  → PackageData.PackageDict[itemID]++ 或新增条目
  → Destroy(物品GameObject)

展示流程：
  GamePlayUiController 监听 InputUI_PackagePanel
  → UIManager.ShowPanel<PackagePanel>()
  → OnShowFadePreComplete(): Time.timeScale=0
  → 遍历 PackageData.PackageDict
  → 为每个物品实例化 PackagePanelItemIcon（数量为 N 则创建 N 个）
  → 默认选中第一个

使用流程：
  PackagePanel.SureButtonOnClick()
  → InventoryManager.RemoveItemFromPackage(itemID)
  → PackagePanelItemIcon.PushSelfToPool() 回收格子
  → EventCenter.EventTrigger(Game_BonusEffect, args)
  → ⚠️ 无监听者，效果不生效

存档流程：
  GameManager.SaveDataAll()
  → RunningDataManager.SaveData(PlayerSaveData)
  → JsonUtility.ToJson(playerSaveData) → 写入 JSON 文件
  → ⚠️ PackageData 内的 Dictionary 无法被 JsonUtility 序列化
```

## 6. 已知问题

### 问题 1：Game_BonusEffect 事件无人监听（严重）

`PackagePanel` 使用物品和 `RestoreHealthPanel` 都会触发 `Game_BonusEffect` 事件，但全局没有任何 `AddEventListener` 注册。物品的回血/回蓝效果**不会实际生效**。

### 问题 2：PackageData 的 Dictionary 无法被 JsonUtility 序列化（严重）

`PackageData.PackageDict` 是 `Dictionary<E_PackageItemID, int>`，Unity 的 `JsonUtility` 不支持 Dictionary 序列化。`RunningDataManager` 使用 `JsonUtility.ToJson` / `JsonUtility.FromJsonOverwrite` 进行存档，背包数据在存档时会被丢失。

### 问题 3：物品数量无堆叠上限

`AddItemToPackage` 没有堆叠上限检查，同一种物品可以无限叠加。

### 问题 4：同种物品重复创建格子

`PackagePanel.OnShowFadePreComplete()` 中，物品数量为 N 就创建 N 个 `PackagePanelItemIcon`，而非创建 1 个格子显示数量标签。当物品数量多时，格子数量膨胀，UI 体验差。

### 问题 5：ItemPickUp 拾取后直接 Destroy

拾取物品后 `Destroy(gameObject)`，如果存档系统在拾取前保存过，读档后物品会重新出现，但拾取后的背包数据可能因序列化问题丢失，造成不一致。

### 问题 6：GetItemInfoByID 使用 LINQ 线性查找

`PackageItemConfigSO.GetItemInfoByID` 用 `PackageItemInfoArray.Where().FirstOrDefault()` 线性查找。当前 3 种物品无影响，但物品数量增长后应改用 Dictionary 缓存。

### 问题 7：缺少物品分类/稀有度/装备系统

当前只有 3 种消耗品，无物品分类（消耗品/材料/装备）、稀有度、装备栏等设计，扩展性不足。

## 7. 优化建议

### P0 — 必须修复（影响核心功能）

**修复 Game_BonusEffect 事件监听缺失**

在 `GameManager` 或 `PlayerController` 中注册 `Game_BonusEffect` 事件监听，根据 `BonusEffectType` 执行回血/回蓝逻辑。

**修复 PackageData 序列化问题**

两种方案：
- 方案 A：将 `Dictionary<E_PackageItemID, int>` 改为可序列化结构（如 `List<PackageItemEntry>`，`PackageItemEntry` 包含 ID 和 Count），`JsonUtility` 可正常序列化
- 方案 B：换用支持 Dictionary 的序列化库（如 Newtonsoft.Json），改动更小但引入外部依赖

推荐方案 A，与项目现有序列化方式一致，不引入新依赖。

### P1 — 建议修复（影响体验）

**格子显示数量而非重复实例化**

`PackagePanel` 中每种物品只创建 1 个格子，在格子上显示数量文本。减少 UI 元素数量，提升性能和体验。

### P2 — 可选优化

**配置查找改用 Dictionary 缓存**

`PackageItemConfigSO` 在 `Awake` 或首次访问时构建 `Dictionary<E_PackageItemID, PackageItemInfo>` 缓存，替换 LINQ 线性查找。

**添加堆叠上限**

在 `PackageItemInfo` 中增加 `MaxStack` 字段，`AddItemToPackage` 检查是否达到上限。

### P3 — 长期扩展

**物品分类系统**

在 `PackageItemInfo` 中增加 `E_ItemCategory`（消耗品/材料/任务物品/装备），UI 按分类筛选展示。

**稀有度系统**

增加 `E_ItemRarity`（普通/稀有/传说），影响图标边框颜色和掉落权重。

**装备系统**

新增装备栏数据结构、装备穿戴逻辑、属性加成计算，与现有 `BonusEffectType` 解耦。
